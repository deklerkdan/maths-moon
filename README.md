# Luna's Maths Moon

A maths game for young learners: adding, taking away, times tables, dividing, fractions and decimals. Get sums right to fill each moon.

Play: https://deklerkdan.github.io/maths-moon/ (its sister game: https://deklerkdan.github.io/word-moon/)

- Works in any modern browser. On a phone, use the browser menu's "Add to Home screen" (or "Install app") to keep it like an app.
- Reading aloud uses the device's own voices. Grown-ups (hold the button) has a voice picker and tips for nicer voices.
- Progress is saved on the device, per name. Grown-ups › Backup copies a code to move progress to another device.

This folder is the published copy. It is built from the source in the LightRain workbench (`Homeschool/maths-moon`, `node build.js`); don't edit `index.html` here by hand.
